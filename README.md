# TMS FNC Localization - Exemplos

Demos, vídeos e informações para utilização do TMS FNC Localization.

O **TMS FNC Localization** traduz a interface de usuário de um aplicativo Delphi sem que você precise mexer nos formulários. No momento do design, ele percorre os componentes do seu projeto, coleta todas as strings traduzíveis que encontra e as armazena em um arquivo de projeto. Você traduz essas strings manualmente, com assistência da IA ou enviando-as para um tradutor externo como XLIFF. Em tempo de execução, o localizador lê o arquivo novamente e aplica as traduções aos componentes ativos, podendo trocar de idioma enquanto a aplicação está em execução.

Ele funciona para VCL, FMX e TMS WEB Core a partir de um único núcleo compartilhado, então um projeto direcionado a mais de um framework usa o mesmo modelo e o mesmo arquivo.
